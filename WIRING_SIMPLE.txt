                          PART 1: THE 3-WIRE UART LINK
═════════════════════════════════════════════════════════════════════════════════

     📷 ESP32-CAM #1                           🤖 ESP32-CAM #2
     (Camera Unit)                             (Servo Unit)

     ┌─────────────┐                           ┌─────────────┐
     │             │                           │             │
     │  [GPIO 4]   │══════════════════════════▶│  [GPIO 4]   │
     │    TX  🔴   │                           │    RX       │
     │             │                           │             │
     │  [GPIO 33]  │◀══════════════════════════│ [GPIO 33]   │
     │    RX  🟡   │                           │    TX       │
     │             │                           │             │
     │   [GND] ⚫  │══════════════════════════▶│   [GND]     │
     │             │                           │             │
     └─────────────┘                           └─────────────┘

     ⚠️ GND MUST BE CONNECTED! UART WON'T WORK WITHOUT IT!


═════════════════════════════════════════════════════════════════════════════════
                    PART 2: SERVO CONNECTIONS (ESP32-CAM #2 ONLY)
═════════════════════════════════════════════════════════════════════════════════

                    🤖 ESP32-CAM #2 (Servo Unit)

                    ┌─────────────────────────┐
                    │                         │
     Thumb    ─────│ [GPIO 12]               │
     Index    ─────│ [GPIO 13]               │
     Middle   ─────│ [GPIO 14]               │
     Ring     ─────│ [GPIO 15]               │
     Pinky    ─────│ [GPIO 2]                │
     Wrist    ─────│ [GPIO 16] (optional)    │
                    │                         │
                    └─────────────────────────┘


     EACH SERVO HAS 3 WIRES:

     ┌─────────┐
     │  Servo  │
     └────┬────┘
          │
     ┌────┴─────┬────────────┐
     │          │            │
     ▼          ▼            ▼
    🟡         🔴          ⚫
  SIGNAL     +5V         GND
  (to ESP32) (to ext)    (to ext)


     ⚠️ USE EXTERNAL 5V POWER! DO NOT POWER SERVOS FROM ESP32-CAM!

═════════════════════════════════════════════════════════════════════════════════
                              ⚠️ CRITICAL ⚠️
═════════════════════════════════════════════════════════════════════════════════

    1. DO NOT power servos from ESP32-CAM! Use external 5V, 2A minimum.
    2. GND MUST connect between: ESP32 #1, ESP32 #2, and Power Supply.
    3. Double-check no 5V is touching GND (short circuit).
    4. GPIO4 connects to GPIO4, GPIO33 connects to GPIO33.
