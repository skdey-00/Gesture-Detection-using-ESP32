                         3 MAIN CONNECTIONS TO MAKE
═════════════════════════════════════════════════════════════════════════════════


    1️⃣  UART (Between ESP32-CAMs)

    📷 ESP32-CAM #1                    🤖 ESP32-CAM #2
    ┌─────────────────┐               ┌─────────────────┐
    │                 │               │                 │
    │ [GPIO 4]  🔴═══════════════════▶│ [GPIO 4]        │
    │ [GPIO 33] 🟡◀═══════════════════│ [GPIO 33]       │
    │ [GND]     ⚫════════════════════▶│ [GND]           │
    │                 │               │                 │
    └─────────────────┘               └─────────────────┘


    2️⃣  I2C (ESP32-CAM #2 → PCA9685)

    🤖 ESP32-CAM #2                     💾 PCA9685
    ┌─────────────────┐               ┌─────────────────┐
    │                 │               │                 │
    │ [GPIO 13] 🟦═══════════════════▶│ [SDA]           │
    │ [GPIO 12] 🟪═══════════════════▶│ [SCL]           │
    │ [3.3V]    🔴═══════════════════▶│ [VCC]           │
    │ [GND]     ⚫════════════════════▶│ [GND]           │
    │                 │               │                 │
    └─────────────────┘               └─────────────────┘


    3️⃣  POWER + SERVOS (PCA9685)

    🔌 Power Supply                    💾 PCA9685
    ┌─────────────────┐               ┌─────────────────┐
    │                 │               │                 │
    │ [+5V]     🔴═══════════════════▶│ [V+]   ┌─────┐ │
    │ [GND]     ⚫════════════════════▶│ [GND]  │ PWM │ │
    │                 │               │       │  0  │─┼──→ Servo 1
    │                 │               │       ├─────┤ │   (Thumb)
    │                 │               │       │  1  │─┼──→ Servo 2
    │                 │               │       ├─────┤ │   (Index)
    │                 │               │       │  2  │─┼──→ Servo 3
    │                 │               │       ├─────┤ │   (Middle)
    │                 │               │       │  3  │─┼──→ Servo 4
    │                 │               │       ├─────┤ │   (Ring)
    │                 │               │       │  4  │─┼──→ Servo 5
    │                 │               │       ├─────┤ │   (Pinky)
    │                 │               │       │  5  │─┼──→ Servo 6
    │                 │               │       └─────┘ │   (Wrist-opt)
    └─────────────────┘               └─────────────────┘

═════════════════════════════════════════════════════════════════════════════════
                              ⚠️  CRITICAL  ⚠️
═════════════════════════════════════════════════════════════════════════════════

    1. GND MUST connect: ESP32 #1, ESP32 #2, PCA9685, Power Supply
    2. Use external 5V for PCA9685 V+ (servo power)
    3. Use ESP32 3.3V for PCA9685 VCC (logic power)
    4. I2C: SDA→SDA, SCL→SCL (NOT crossed like UART!)
