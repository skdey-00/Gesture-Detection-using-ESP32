ESP32-CAM #1 (Camera & Game Logic):
├── UART1 TX:  GPIO4   ───► RX of ESP32-CAM #2
├── UART1 RX:  GPIO33  ◄─── TX of ESP32-CAM #2
├── Camera:    OV2640  (standard AI-Thinker pins)
└── Power:     5V/2A minimum
└── WiFi AP:   "ESP32-CAM" / "12345678"

ESP32-CAM #2 (Servo Controller):
├── UART1 RX:  GPIO4   ◄─── TX of ESP32-CAM #1
├── UART1 TX:  GPIO33  ───► RX of ESP32-CAM #1
├── Servo 1:   GPIO12  (Thumb)
├── Servo 2:   GPIO13  (Index)
├── Servo 3:   GPIO14  (Middle)
├── Servo 4:   GPIO15  (Ring)
├── Servo 5:   GPIO2   (Pinky)
├── Servo 6:   GPIO16  (Wrist, optional)
└── Power:     USB + external 5V for servos

CRITICAL: ALWAYS CONNECT GND BETWEEN BOTH ESP32-CAMs FOR UART TO WORK!

╔═══════════════════════════════════════════════════════════════════════════════╗
║                         GAME FLOW SEQUENCE                                      ║
╚═══════════════════════════════════════════════════════════════════════════════╝

1. USER makes gesture (Rock/Paper/Scissors) in front of camera
                   │
                   ▼
2. PYTHON SERVER detects gesture using MediaPipe
                   │
                   ▼
3. USER clicks "PLAY ROUND" button on web interface
                   │
                   ▼
4. PYTHON SERVER sends HTTP request to ESP32-CAM #1
   GET /play?move=rock
                   │
                   ▼
5. ESP32-CAM #1 sends UART command: "PLAY\n"
   ┌─────────────────────────────────┐
   │ GPIO4 (TX) ──────> GPIO4 (RX)  │
   │ ESP32-CAM #1     ESP32-CAM #2   │
   └─────────────────────────────────┘
                   │
                   ▼
6. ESP32-CAM #2 receives UART, randomly selects move
                   │
                   ▼
7. ESP32-CAM #2 moves servos to physical gesture
                   │
                   ▼
8. ESP32-CAM #2 sends UART response: "MOVE:paper\n"
   ┌─────────────────────────────────┐
   │ GPIO33 (RX) ◄──── GPIO33 (TX)  │
   │ ESP32-CAM #1     ESP32-CAM #2   │
   └─────────────────────────────────┘
                   │
                   ▼
9. ESP32-CAM #1 determines winner (rock > scissors, etc.)
                   │
                   ▼
10. ESP32-CAM #1 updates scores and returns JSON to Python
                   │
                   ▼
11. WEB INTERFACE displays result
                   │
                   ▼
12. Game continues! (Scores tracked across rounds)
