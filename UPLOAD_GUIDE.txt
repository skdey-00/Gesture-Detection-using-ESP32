    THIS ONE STREAMS VIDEO + RUNS THE GAME

    Open this file in Arduino IDE:
    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │    esp32_camera/esp32_camera.ino                           │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

    Settings in Arduino IDE:
    • Tools → Board → AI Thinker ESP32-CAM
    • Tools → Port → (your COM port)
    • Tools → Upload Speed → 115200

    Click UPLOAD

═════════════════════════════════════════════════════════════════════════════════

                        🚨 UPLOAD ORDER MATTERS!

═════════════════════════════════════════════════════════════════════════════════

    Step 1: Upload to ESP32-CAM #2 (Servo) first
    Step 2: Then upload to ESP32-CAM #1 (Camera)
    Step 3: Then run Python server

    Why? ESP32-CAM #1 tries to talk to #2 on startup!


═════════════════════════════════════════════════════════════════════════════════

                        🔌 PHYSICAL SETUP

═════════════════════════════════════════════════════════════════════════════════

    Before uploading anything, wire it up like this:

    ┌─────────────┐                  ┌─────────────┐
    │ ESP32-CAM #1│                  │ ESP32-CAM #2│
    │  (Camera)   │                  │  (Servo)    │
    └──────┬──────┘                  └──────┬──────┘
           │                                │
           │   GPIO4 ════════════════════════▶│ GPIO4
           │   GPIO33 ◀═══════════════════════│ GPIO33
           │   GND ══════════════════════════▶│ GND
           │                                │
           │                          ┌──────┴──────┐
           │                          │   PCA9685   │
           │                          │             │
           │                          │ SDA ◀───────│ GPIO13
           │                          │ SCL ◀───────│ GPIO12
           │                          │ VCC ◀───────│ 3.3V
           │                          │ GND ◀───────│ GND
           │                          │             │
           │                          │ PWM0-5 ────▶│ Servos
           │                          └─────────────┘
           │
    ┌──────┴─────────────────────────────────────┐
    │                                          │
    │         YOUR COMPUTER                     │
    │         (runs Python server)              │
    │         (connects via WiFi)               │
    └──────────────────────────────────────────┘
